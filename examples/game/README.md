# Orb Runner — بازی نمونهٔ HollowEngine 2.1

حلقهٔ کامل یک بازی واقعی روی موتور: کلاس Orb، فیزیک (جاذبه+برخورد)،
spawn، سایه و fog.

```bash
./hollow run examples/game --frames 300   # خروجی قطعی: FINAL SCORE: 6
./hollow render examples/game             # frame.png
./hollow editor examples/game             # F5 → با کلیدهای جهت بازی کن
```
